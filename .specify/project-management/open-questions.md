# 项目管理与预配置模块待确认事项

**状态**：全部问题已确认，作为项目管理模块规格的决策输入。  
**范围**：项目、代码仓库、凭据引用、部署环境及其授权边界。  
**非范围**：流水线 YAML、运行编排、插件执行、产物、LLM/MCP 业务工具和数据库表设计。  
**依据**：[产品定义](../product.md)、[模块 TODO](../module-todo.md)、[IAM 授权模型](../iam/authorization-model.md)。

## 已知前提

- IAM 已提供用户、租户成员关系和统一授权入口；项目模块只提交“资源 + 动作 + 范围”进行鉴权，不依赖 IAM 的角色实现细节。
- 项目是租户内的隔离边界；仓库、环境及未来流水线、运行和产物都归属项目。
- 当前 MVP 的既定构想是：公开 GitHub 仓库、Maven/Java 构建，以及 Kubernetes 部署；私有仓库和任意远程 Shell 不在已确认范围内。
- 凭据不得以明文出现在 API 响应、日志、错误信息、流水线 YAML 或 LLM 上下文中。
- 当前不做审计模块；本文件不新增审计实现要求。
