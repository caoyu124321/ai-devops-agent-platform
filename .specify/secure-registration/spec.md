# 安全注册链接

**修订版本**：0.1  
**状态**：待需求检查  
**关联模块**：IAM、Codex MCP

## 目标

当 Codex 客户端不支持 MCP 安全输入提示时，未注册用户仍可在不向对话、MCP 工具参数或模型上下文提交密码的前提下注册 AI DevOps 账号。

## 范围

- Codex MCP 生成本机平台的短时、一次性注册链接。
- 平台提供只用于注册的本机浏览器页面，并在页面中收集用户名、邮箱和密码。
- 平台在注册链接失效、被取消或已完成时拒绝再次注册。
- MCP 可查询由其创建的注册链接是否已完成，结果只包含安全用户摘要。

## 非范围

- 登录、找回密码、OAuth、远程平台注册或通用网页管理界面。
- 在 MCP 工具输入、输出、日志或工作区文件中传递密码。
- 通过链接自动创建会话、保存 Token 或自动登录。

## 用户故事

### US-SR-01 取得安全注册链接

作为未注册的 Codex 用户，我希望得到一个短时注册链接，以便在浏览器中安全设置密码，而无需在对话中粘贴密码。

**验收场景**：

- AS-SR-01.1：创建链接工具的普通输入 Schema 不包含用户名、邮箱或密码。
- AS-SR-01.2：工具返回一个仅指向本机 AI DevOps 服务的链接、稳定注册链接标识和过期时间。
- AS-SR-01.3：链接、工具输出和日志不包含密码、密码哈希或平台会话 Token。

### US-SR-02 在注册链接页面完成注册

作为取得注册链接的用户，我希望在本机浏览器页面提交注册信息，以便平台直接创建账号。

**验收场景**：

- AS-SR-02.1：合规信息通过链接页面提交后创建用户，页面仅显示安全用户摘要与完成状态。
- AS-SR-02.2：密码只从浏览器页面发送到平台注册接口；MCP 不接收、保存或输出密码。
- AS-SR-02.3：重复使用已成功完成的链接不创建第二个用户。
- AS-SR-02.4：过期、取消、未知或令牌不匹配的链接不显示注册表单，也不泄露注册链接状态。

### US-SR-03 查询注册链接完成状态

作为发起注册链接的 Codex 用户，我希望查询注册链接是否已完成，以便确认用户可以继续登录。

**验收场景**：

- AS-SR-03.1：注册链接完成后，MCP 查询结果仅返回 `COMPLETED` 和安全用户摘要。
- AS-SR-03.2：未完成、过期或不存在链接不会返回用户名、邮箱或其他账号信息。
- AS-SR-03.3：注册链接不创建、覆盖或删除 Windows 凭据管理器中的平台 Token。

## 功能需求

- FR-SR-001：注册链接必须为随机、不可预测的持有者令牌，平台只保存其不可逆哈希。
- FR-SR-002：注册链接有效期固定为 15 分钟，且仅可成功完成一次。
- FR-SR-003：注册链接仅允许访问配置的本机平台地址；MCP 不得生成公网注册链接。
- FR-SR-004：注册链接表单与提交接口不得在日志、异常或响应中暴露密码或密码哈希。
- FR-SR-005：注册链接状态至少包含待完成、已完成和过期，并记录创建与完成时间。
- FR-SR-006：MCP 工具只能保存必要的注册链接引用以查询状态；不得将密码或平台 Token 写入凭据管理器。
- FR-SR-007：注册链接创建、完成、查询和失效必须返回稳定的安全错误；无效链接不泄露其是否曾存在。

## 成功标准

- 用户可在不向 Codex 对话发送密码的情况下完成注册。
- 链接有效期内只允许成功创建一个账号。
- 所有验收场景均有自动化测试覆盖。

## 待解决问题

无。注册链接仅作为不支持 MCP 安全输入提示时的注册回退；支持该能力的客户端仍可在后续版本使用其原生安全交互。
