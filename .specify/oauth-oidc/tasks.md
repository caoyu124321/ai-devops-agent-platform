## 推荐验收顺序

1. Discovery、动态注册与回调地址校验。
2. 浏览器授权、PKCE、授权码兑换。
3. Access Token 调用 MCP 与 IAM 授权拒绝。
4. Refresh Token 轮换、重用检测和时间边界。
5. 改密、登出、客户端停用后的撤销。
6. 本地 `127.0.0.1` URL 型 MCP 登录。
7. HTTPS 反向代理环境下的真实 Agent 登录。
