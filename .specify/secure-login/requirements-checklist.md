# 安全登录链接需求检查清单

| 检查项 | 结论 | 说明 |
| --- | --- | --- |
| 用户价值明确 | 通过 | 避免 Codex 输入提示崩溃，并保持密码不进入对话。 |
| 密码与 Token 边界明确 | 通过 | 密码仅进入浏览器到 IAM 的请求；会话令牌原文仅在 MCP 内存和当前 Windows 用户的凭据管理器中存在。 |
| 会话创建责任明确 | 通过 | IAM 创建普通平台会话，MCP 只保管已知原始令牌。 |
| 生命周期明确 | 通过 | 链接 15 分钟有效、仅完成一次；完成后可查询 24 小时会话失效时间。 |
| stdio 重启恢复明确 | 通过 | 待完成链接加密保存，完成或过期即清理。 |
| 活动会话回退明确 | 通过 | 没有待完成链接时，状态工具改为查询当前 Windows 用户的有效活动会话。 |
| 失败行为明确 | 通过 | 无效链接和登录失败均不泄露资源或账号细节，且不覆盖已有凭据。 |
| 可测试性明确 | 通过 | 链接、登录、会话交接和 MCP 状态均可由服务及 HTTP 契约测试覆盖。 |

**结论**：无阻塞性歧义，可进入实施计划。
