# 安全登录链接实施计划

## 设计

1. MCP 生成随机平台会话令牌，仅向 IAM 发送 SHA-256 哈希。
2. IAM 将会话令牌哈希与一次性登录链接关联；浏览器完成登录后，IAM 以该哈希创建普通会话。
3. 浏览器不接收平台会话令牌；MCP 在创建时将待完成链接及原始令牌保存在当前 Windows 用户的凭据管理器，查询完成后转为活动会话并清理待完成记录；没有待完成链接时，状态工具读取活动会话并校验其用户身份。
4. 登录链接状态用数据库行锁保证仅成功完成一次，过期链接不可使用。

## 数据与接口

新增 `iam_login_links`，保存链接令牌哈希、会话令牌哈希、状态、创建/过期/完成时间、用户和会话失效时间。

- `POST /api/v1/auth/login-links`：MCP 提交会话令牌哈希，创建登录链接。
- `GET /api/v1/auth/login-links/{id}`：MCP 以持有者令牌查询状态。
- `GET /api/v1/auth/login-links/{id}/form`：浏览器显示登录表单。
- `POST /api/v1/auth/login-links/{id}/complete`：浏览器提交登录信息。

## 任务

1. 建立登录链接迁移、DAO 与状态服务。
2. 复用 IAM 登录锁定规则，以预生成令牌哈希创建会话。
3. 提供浏览器表单与安全状态接口。
4. 将 MCP 登录工具改为创建/查询登录链接。
5. 增加测试、打包并更新接入规格。
6. 状态工具优先查询待完成链接；不存在时回退读取活动会话，避免进程重启后将有效会话误报为未创建链接。
