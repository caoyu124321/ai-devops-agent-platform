# 安全登录链接

**修订版本**：0.3  
**状态**：已完成需求检查  
**关联模块**：IAM、Codex MCP

## 目标

当 Codex 不支持或无法稳定使用 MCP 安全输入提示时，已注册用户可通过一次性本机浏览器链接登录 AI DevOps，且密码不进入对话、MCP 工具参数或模型上下文。

## 范围

- MCP 创建短时一次性本机登录链接，并在当前 Windows 用户的凭据管理器中临时保留仅用于成功登录后的会话令牌。
- 浏览器页面直接向 IAM 提交登录标识和密码。
- 登录成功后，MCP 通过链接状态将预生成的会话令牌保存至 Windows 凭据管理器。
- MCP 可查询当前登录链接或已保存的本机会话状态，并在完成后返回安全用户摘要与登录状态。

## 非范围

- OAuth、远程登录、多平台凭据存储、找回密码和刷新 Token。
- 在 MCP 工具输入、输出、日志或工作区文件中传递密码或平台会话 Token。
- 将浏览器登录链接作为可跨设备使用的登录方式。

## 用户故事

### US-SL-01 创建安全登录链接

作为已注册用户，我希望在 Codex 中取得安全登录链接，以便在浏览器中输入用户名和密码后登录平台。

**验收场景**：

- AS-SL-01.1：登录工具普通输入 Schema 不包含用户名、邮箱或密码。
- AS-SL-01.2：工具仅返回指向本机平台的链接、稳定链接标识和过期时间，不返回平台会话 Token。
- AS-SL-01.3：链接、MCP 输出和日志不包含密码、密码哈希或平台会话 Token。

### US-SL-02 完成浏览器登录

作为取得登录链接的用户，我希望在本机浏览器中提交登录信息，以便安全创建当前 Codex 使用的平台会话。

**验收场景**：

- AS-SL-02.1：正确登录信息创建 24 小时平台会话，浏览器页面只显示安全用户摘要与完成状态。
- AS-SL-02.2：密码只从浏览器页面发送到 IAM；MCP 不接收、保存或输出密码。
- AS-SL-02.3：链接过期、已完成、未知或令牌不匹配时不显示登录表单，也不泄露链接状态。
- AS-SL-02.4：密码错误与账号锁定均只显示通用登录失败结果，且不写入活动平台会话凭据。

### US-SL-03 将登录会话交给 MCP

作为完成浏览器登录的用户，我希望 Codex 在查询登录状态后保存会话，以便后续工具自动以我的身份运行。

**验收场景**：

- AS-SL-03.1：登录链接完成后，状态工具只返回 `LOGGED_IN`、安全用户摘要和会话失效时间。
- AS-SL-03.2：状态工具仅在完成后写入 Windows 凭据管理器；未完成或过期链接不改变已有会话。
- AS-SL-03.3：平台数据库只保存会话令牌哈希；MCP 原始令牌不发送到浏览器、不返回给 Codex。
- AS-SL-03.4：当前不存在待完成登录链接但活动会话仍有效时，状态工具返回 `LOGGED_IN`、安全用户摘要和会话失效时间，不返回“尚未创建登录链接”。

## 功能需求

- FR-SL-001：登录链接必须为随机、不可预测的持有者令牌，平台只保存其不可逆哈希。
- FR-SL-002：登录链接有效期固定为 15 分钟，只可成功完成一次。
- FR-SL-003：MCP 必须预生成平台会话令牌，仅向平台提交其哈希；平台不得持久化原始令牌。
- FR-SL-004：链接完成后，平台使用 MCP 提交的会话令牌哈希创建普通 24 小时会话。
- FR-SL-005：登录链接状态至少包含待完成、已完成和过期，并记录创建、完成与会话失效时间。
- FR-SL-006：链接页面、MCP 工具和日志不得输出密码、密码哈希、链接令牌或平台会话令牌。
- FR-SL-007：无效链接统一返回安全错误，不泄露链接是否存在或具体登录失败原因。
- FR-SL-008：待完成登录链接必须由当前 Windows 用户的凭据管理器保存，以支持 stdio MCP 进程重启后的状态查询；完成或过期后立即清理。
- FR-SL-009：状态工具在没有待完成登录链接时，必须查询当前 Windows 用户凭据管理器中的活动会话；会话有效时返回 `LOGGED_IN`、安全用户摘要和失效时间。

## 成功标准

- 用户无需向 Codex 对话提供密码即可完成登录。
- 成功登录后，受保护 MCP 工具可使用保存的会话。
- 所有验收场景均由自动化测试覆盖。
