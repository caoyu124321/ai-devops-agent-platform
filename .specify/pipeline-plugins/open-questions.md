# 首批插件待确认事项

| 编号 | 待确认决策 | 推荐选项 | 影响 |
| --- | --- | --- | --- |
| PPQ-001 | 构建镜像允许来源 | 平台管理员配置镜像不可变摘要白名单 | 决定 Maven 插件的镜像校验和供应链风险控制。 |
| PPQ-002 | Maven goals 白名单 | MVP 只允许 `test`、`package` 和 `verify` | 决定是否可能借 Maven profile 间接执行任意外部行为。 |
| PPQ-003 | Docker 运行配额 | 每步骤 30 分钟、2 CPU、4 GiB 内存、20 GiB 临时磁盘，后续可配置 | 决定容器运行器的资源限制和超时语义。 |
| PPQ-004 | Kubernetes 清单类型 | MVP 仅原生 YAML，禁止 Helm、Kustomize 远程基和 CRD 创建 | 决定部署插件的解析器与策略范围。 |
| PPQ-005 | 产物后端 | 本地文件系统仅用于开发；生产使用对象存储 | 决定产物模块接口与部署拓扑，不能由插件自行假设。 |
| PPQ-006 | Kubernetes 回滚 | MVP 不自动回滚，只返回资源变更与失败信息 | 决定部署失败的恢复责任边界。 |
