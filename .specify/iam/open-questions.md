# IAM 决策记录与待确认问题

## 已确认决策

| 编号 | 决策 | 影响 |
| --- | --- | --- |
| IAM-Q01 | 默认开放注册，暂不支持关闭。 | 注册接口为公开入口。 |
| IAM-Q02 | 用户名和邮箱均可登录；邮箱唯一。 | 注册、登录和邀请均需校验唯一身份。 |
| IAM-Q03 | Token 有效期 24 小时；改密立即撤销全部会话；本期不支持账号禁用。 | 认证层需支持会话撤销，不能只依赖无状态 Token 到期。 |
| IAM-Q04 | 仅邀请已注册用户。 | 不需要邮箱邀请后的注册衔接。 |
| IAM-Q05 | 租户角色提供默认能力；不支持修改内置角色权限项，也不支持自定义角色。 | 精确权限通过范围授权项表达。 |
| IAM-Q06 | 不提供显式拒绝授权项管理界面，仅保留扩展能力。 | MVP 仅配置允许授权，默认拒绝。 |
| IAM-Q07 | PROD 不需要二次确认；有生产部署权限即可部署。 | IAM MVP 不提供确认接口，PROD 直接走 `environment.deploy` 授权。 |
| IAM-Q08 | 已开始任务以启动时权限为准。 | 后续运行模块不因角色变更自动中止已开始任务。 |

## 已确认的跨模块规则

| 编号 | 决策 | 模块边界 |
| --- | --- | --- |
| IAM-C01 | 权限或角色变更后，IAM 不直接停止任务。IAM 发布角色/授权变更事件；流水线调度模块监听事件后重新调用统一授权接口，并根据其运行策略决定是否停止受影响流水线。 | IAM 只负责身份、授权决策和事件发布；调度模块负责任务生命周期。 |

IAM 模块已无阻塞性产品问题，可进入技术设计阶段。

## 技术设计输入（2026-07-18）

| 项目 | 已确认规则 |
| --- | --- |
| 平台超级管理员 | 不需要；平台不提供跨租户超级管理角色。 |
| 密码 | 不提供找回密码；至少 8 位，必须同时包含字母和数字，不强制特殊字符。 |
| 登录失败 | 同一账号连续失败 5 次后锁定 15 分钟；不限制登录频率。 |
| 会话 | 允许多设备同时登录；Token 有效期 24 小时；改密后撤销全部会话。 |
| 租户名称 | 可重复；同一用户可创建多个同名租户。 |
| 项目管理员 | 默认拥有其项目 PROD 环境的部署权限。 |
| Token 形式 | 使用随机不透明 Token；数据库仅保存 Token 哈希，便于单会话和全会话撤销。 |
| 邀请撤销 | 租户管理员支持撤销尚未处理的邀请。 |
| 租户名称 | 必填，1–128 个字符；允许中文、英文、数字、空格和常用符号；允许重复。 |
| 授权项管理 | 租户管理员可管理租户内全部授权项；项目管理员仅可管理自己项目范围内的授权项。 |
| 管理员自我操作 | 可主动退出但受最后管理员保护；不得通过修改自身角色绕过保护。 |
| 事件投递 | 仅使用进程内广播，不使用数据表或持久化投递。 |
