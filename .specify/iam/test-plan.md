# IAM 测试策略

## 单元测试

- 密码策略：少于 8 位、缺少字母或缺少数字时拒绝；符合规则的密码允许包含或不包含特殊字符。
- 密码哈希与密码明文脱敏。
- 登录失败计数、5 次锁定、15 分钟解锁、成功登录清零。
- 会话撤销、单会话登出、改密全会话撤销。
- 邀请有效期、重复邀请、接受/拒绝、最后管理员保护。
- 授权范围继承、默认拒绝、项目管理员 PROD 授权、跨租户拒绝。

## 接口与契约测试

- 用户名/邮箱均能登录，错误登录不泄露账号存在性。
- 未认证、无权限、安全可见的不存在资源三类错误一致。
- 授权注解拦截器正确组装授权请求。
- 授权接口可表达租户 T、项目 X、环境 Y、`PROD`、`environment.deploy`。

## 安全与回归测试

- Token 过期、撤销、登出、改密后访问。
- 成员移除和角色变更后的下一次授权检查。
- 错误响应、日志和事件中不存在密码、Token、凭据与 Kubernetes 配置。
- 并发邀请、并发管理员角色变更的最后管理员保护。
