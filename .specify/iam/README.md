# 租户、用户与统一授权能力

## 模块目标

提供平台身份认证、租户成员关系、内置角色、基于“资源 + 动作 + 范围”的统一授权判断、确认授权边界。后续模块必须调用本模块的授权入口，禁止直接比较角色。

## 能力范围

- 用户注册、登录、登出、改密与认证失效。
- 多租户成员关系、邀请、加入/拒绝、移除、退出、管理员变更。
- 内置角色及资源权限定义
- token认证鉴权注解拦截器
- 统一授权决策接口与后续模块可订阅的撤权事件契约。

## 术语

| 术语 | 含义 |
| --- | --- |
| 用户 | 平台身份主体，可属于多个租户。 |
| 租户 | 资源和成员的顶层隔离边界。 |
| 成员 | 用户在某个租户中的身份与角色集合。 |
| 角色 | 内置权限集合，不直接等于授权结果。 |
| 资源 | 被保护对象，如租户、项目、环境。 |
| 动作 | 对资源执行的操作，如查看、管理、部署。 |
| 范围 | 平台、租户、项目或环境的资源边界。 |

## 边界与交互

本模块接收抽象资源标识（`tenantId`、`projectId`、环境等级），不读取项目或环境的业务数据。后续模块负责提供资源归属上下文，再调用 `authorize` / `requireAuthorization` 获得允许或拒绝结果。

本模块向后续模块发布抽象事件：`TenantMemberRemoved`、`RoleChanged`、`AuthorizationRevoked`。IAM 不监听、取消或停止任务；流水线调度模块未来监听这些事件，重新调用统一授权决策，并依据其自身的运行策略决定是否停止受影响任务。本阶段仅定义事件契约和空监听扩展点。

## 已确认规则

- 注册默认开放；用户名和邮箱均可登录，邮箱必须唯一。
- Token 有效期为 24 小时；改密会立即撤销该用户全部会话。本期不支持账号禁用。
- 仅允许邀请已注册用户；邀请有效期 7 天，未过期重复邀请必须拒绝。
- 仅支持内置角色，不支持自定义角色或修改内置角色权限项。
- PROD 不需要二次确认；只有拥有生产环境部署权限的用户可部署。
