## 执行规则

- 每项任务完成后必须通过对应测试，才可标记完成。
- 不实现项目、环境、流水线、插件、产物或 MCP 的业务能力。
- 不在业务模块直接比较角色；所有授权经统一授权接口或注解拦截器。
- 每次代码提交应关联一个或多个任务编号。

## 阶段 1：公共基础与错误契约

- [x] **IAM-T000** 基于 `data-model.md` 评审并冻结 IAM 数据模型、约束、索引和事务边界。
  - 依赖：无。
  - 完成标准：表结构与用户故事、授权模型、事件要求一致；无业务模块表被提前引入。
  - 测试：评审数据完整性、唯一性、最后管理员与跨租户隔离约束。

- [ ] **IAM-T001** 建立 Maven 聚合工程中的 IAM 独立模块边界与公开契约目录；后续模块只能依赖其认证主体、授权请求、授权决策和事件契约。
  - 依赖：IAM-T000。
  - 完成标准：IAM 具有独立的构建边界；公开契约与内部实现分离；后续模块不能依赖 IAM 内部包；编译边界检查通过。
  - 测试：契约对象不可包含密码、Token 或凭据字段。
- [ ] **IAM-T001A** 配置 IAM 持久化基础设施：接入现有 MySQL IAM 表、建立 DAO 层映射，并完成连接与时间约定校验。
  - 依赖：IAM-T001。
  - 完成标准：数据库连接信息仅从外部配置读取；连接会话按 UTC 处理时间；为 `iam_users`、`iam_sessions`、`iam_login_locks`、`iam_tenants`、`iam_tenant_members`、`iam_invitations`、`iam_authorization_grants` 建立 DAO 访问边界；启动时仅校验既有结构，不重复建表或修改生产数据。
  - 测试：针对测试数据库验证连接、UTC 时间读写、七张表映射和关键唯一/外键约束；不得使用真实密码或生产数据。

- [ ] **IAM-T002** 定义认证、授权、邀请、最后管理员和登录锁定的统一错误代码及响应映射。
  - 依赖：IAM-T001。
  - 完成标准：错误响应包含稳定 `code`、`message`、`traceId` 和安全的 `details`。
  - 测试：未认证、无权限、资源不可见、登录失败的错误不会泄露敏感信息。

- [ ] **IAM-T003** 定义进程内授权变更事件构造器、广播接口和敏感字段脱敏器。
  - 依赖：IAM-T001。
  - 完成标准：密码、Token、Authorization 头、凭据与 Kubernetes 配置无法进入事件载荷；不创建事件持久化表。
  - 测试：针对嵌套对象、异常信息与请求上下文的脱敏测试，以及同进程订阅者广播测试。

## 阶段 2：身份、密码与会话

- [ ] **IAM-T004** 实现注册用例：用户名、唯一邮箱和密码策略校验。
  - 依赖：IAM-T001、IAM-T001A、IAM-T002、IAM-T003。
  - 完成标准：密码至少 8 位且含字母和数字；不强制特殊字符；返回用户安全摘要。
  - 测试：用户名/邮箱冲突、少于 8 位、缺字母、缺数字、允许特殊字符。

- [ ] **IAM-T005** 实现密码哈希、密码比对和密码变更用例。
  - 依赖：IAM-T004。
  - 完成标准：使用经配置的自适应不可逆密码哈希算法；限定合理的最大输入长度；不保存或输出密码明文；改密需验证旧密码。
  - 测试：正确/错误旧密码、新密码策略、日志和事件不泄露密码。

- [ ] **IAM-T006** 实现多设备会话、24 小时访问 Token 和当前会话登出。
  - 依赖：IAM-T004、IAM-T002。
  - 完成标准：每次登录使用密码学安全随机源签发不透明 Token 并创建独立会话；数据库仅保存 Token 哈希；登出仅撤销当前会话；重复登出幂等。
  - 测试：用户名/邮箱登录、多会话、Token 过期、已撤销 Token。

- [ ] **IAM-T007** 实现按账号标识的登录失败锁定策略。
  - 依赖：IAM-T006。
  - 完成标准：连续失败 5 次锁定 15 分钟；成功登录清零；不实施 IP 限流。
  - 测试：第五次失败、锁定期间、15 分钟后、成功登录重置。

- [ ] **IAM-T008** 实现改密后的全会话撤销和 `PasswordChanged` 事件。
  - 依赖：IAM-T005、IAM-T006。
  - 完成标准：改密后所有旧 Token 在下一次请求被拒绝。
  - 测试：多设备登录后改密、当前会话与其他会话均失效、事件不含密码。

- [ ] **IAM-T009** 实现注册、登录、登出、改密、`GET /me` 的 REST 接口与认证拦截器。
  - 依赖：IAM-T004 至 IAM-T008。
  - 完成标准：接口符合 `api-plan.md`，认证主体可安全注入后续接口。
  - 测试：接口契约、认证失败隐藏、会话撤销行为。

## 阶段 3：租户、成员与邀请

- [ ] **IAM-T010** 实现租户创建与“我的租户”查询。
  - 依赖：IAM-T009。
  - 完成标准：允许同名租户；创建者自动成为首位租户管理员。
  - 测试：同一用户创建同名租户、多租户隔离。

- [ ] **IAM-T011** 实现租户成员关系与内置角色分配。
  - 依赖：IAM-T010。
  - 完成标准：同一用户在同一租户仅有一条有效成员关系；仅支持固定内置角色。
  - 测试：重复成员、未知角色、成员租户归属。

- [ ] **IAM-T012** 实现邀请创建、查询、接受、拒绝、管理员撤销和过期清理。
  - 依赖：IAM-T011、IAM-T003。
  - 完成标准：仅邀请已注册用户；有效期 7 天；未过期重复邀请拒绝；支持管理员撤销；过期记录删除。
  - 测试：全部邀请状态、身份不匹配、撤销、过期、并发重复邀请。

- [ ] **IAM-T013** 实现角色修改、管理员转移、成员移除和成员主动退出。
  - 依赖：IAM-T011、IAM-T012。
  - 完成标准：最后管理员不可退出、移除或降级；必须先授予其他成员管理员角色。
  - 测试：最后管理员保护、角色立即生效、跨租户拒绝。

## 阶段 4：统一授权与事件

- [ ] **IAM-T014** 实现 `AuthorizationRequest`、`AuthorizationDecision` 和资源/动作/范围常量。
  - 依赖：IAM-T001。
  - 完成标准：请求契约支持平台、租户、项目、环境范围及 TEST/STAGING/PROD 等级上下文；本期不提供平台角色或平台级授权项，平台范围请求默认拒绝。
  - 测试：请求完整性、非法资源/动作/范围组合、平台范围默认拒绝。

- [ ] **IAM-T015** 实现内置角色默认授权映射与范围继承规则。
  - 依赖：IAM-T011、IAM-T014。
  - 完成标准：租户管理员仅覆盖所属租户；项目管理员默认允许所属项目 PROD 部署；默认拒绝。
  - 测试：四个内置角色、上下级范围、跨租户、PROD 部署。

- [ ] **IAM-T016** 实现项目级、环境级授权项合并与统一 `authorize` / `requireAuthorization` 服务。
  - 依赖：IAM-T015。
  - 完成标准：可判断用户对指定租户、项目、环境和动作的授权；不依赖项目/环境业务实现。
  - 测试：补充/收窄授权、无匹配拒绝、资源归属上下文不一致。

- [ ] **IAM-T017** 实现声明式授权注解和拦截器适配层。
  - 依赖：IAM-T009、IAM-T016。
  - 完成标准：接口仅声明动作与资源参数来源，由拦截器调用统一授权服务。
  - 测试：注解授权成功/拒绝、未认证、资源不存在信息隐藏。

- [ ] **IAM-T018** 实现成员移除、角色变更、授权撤销事件发布接口。
  - 依赖：IAM-T013、IAM-T016。
  - 完成标准：IAM 仅发布事件，不停止任务；事件载荷不含敏感信息。
  - 测试：事件内容、同进程订阅者通知和后续模块可订阅的契约测试。
- [ ] **IAM-T019** 实现授权项查询、授予与撤销用例及其 REST 接口。
  - 依赖：IAM-T016、IAM-T017、IAM-T018。
  - 完成标准：接口符合 `api-plan.md`；租户管理员可管理本租户全部授权项；项目管理员仅可管理经资源归属验证的本人项目授权项；撤销后发布 `AuthorizationRevoked`；不得提前实现项目或环境业务表。
  - 测试：授权项唯一性、跨租户拒绝、项目范围限制、PROD 显式授权、撤销后的重新鉴权与事件发布。
