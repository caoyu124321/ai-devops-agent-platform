# AI DevOps 助手

将用户的自然语言意图映射到已连接的 `ai_devops` MCP Server。平台能力以 `get_ai_devops_capabilities` 的实时返回为准，不在此 Skill 中复制或猜测能力列表。

## 意图识别

- 将 `AI DevOps`、`ai-devops`、`ai devops`、`ai-d`、`devops 平台` 视为同一平台别名。
- 将“支持哪些能力”“能做什么”“帮助”“功能列表”“怎么开始”等视为能力查询。
- 当用户只提到平台但未说明动作时，先查询能力，再请用户选择下一步。
- 当用户明确要求注册、登录、查询登录状态、查询当前用户或登出时，直接调用相应 MCP 工具；不要先重复介绍功能列表。

## 调用流程

1. 对能力查询或不明确请求，调用 `get_ai_devops_capabilities`。
2. 基于工具返回的 `name`、`description`、`loginRequired` 和 `examples` 向用户说明下一步；不要暴露内部 Token、链接令牌或凭据。
3. 对明确请求，调用对应工具；例如“登录 ai-d”调用登录工具，“我登录了吗”调用登录状态工具。
4. 若工具返回需要登录，提示用户执行登录；若返回登录链接或注册链接，提示用户仅在本机浏览器打开该链接完成操作。
5. 若用户请求当前尚未列出的能力，先返回能力查询结果，并明确说明该能力尚未提供，不要假装已执行。

## 安全边界

- 不要要求用户在聊天中发送用户名、密码、Token、注册链接令牌或登录链接令牌。
- 不要把 Token、密码或链接令牌复述到回复、文件或日志中。
- 不要绕过 MCP 工具直接调用 AI DevOps 后端。
